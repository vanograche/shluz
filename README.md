# Шлюз

Прототип хаба подписок: под каждый сервис своя виртуальная карта, переключатель «вкл/выкл», пауза до даты, предел списаний, одноразовые карты для пробных периодов, кошелёк с пополнением, тарифы.

Открыть: https://vanograche.github.io/shluz/

Все данные в прототипе вымышленные, состояние хранится в браузере.
